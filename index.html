Fast, Accurate Machine Learning with Gaussian Processes

FoKL-GPy is a Python package designed for scalable Gaussian Process regression with forward variable selection. Built for speed and accuracy, it enables fast inference on both static and dynamic datasets while maintaining significant predictive power.

Fast Inference

Leverage Karhunen-Loève decomposition for scalable GP regression. Get rapid predictions on large datasets without sacrificing accuracy.

Symbolic Equations

Export your trained models as symbolic equations. Seamlessly integrate GP models into optimization frameworks like Pyomo.

Derivatives & Gradients

Compute first and second derivatives of your model with respect to any input variable. Perfect for sensitivity analysis and optimization.

User-Friendly API

Automatic handling of various dataset formats, intelligent training set creation, and intuitive hyperparameter tuning make FoKL easy to use.

Model Persistence

Save, share, and load trained models effortlessly. Import and evaluate models without requiring the original training data.

Multiple Backends

Choose from standard FoKL, FoKL[pyomo] for optimization, or FoKL[JAX] for accelerated computation on GPUs.

Quick Start

# Import FoKL from fokl import FoKL # Initialize and train model = FoKL() model.fit(X_train, y_train) # Make predictions y_pred = model.predict(X_test) # Export as symbolic equation equation = model.to_symbolic() # Compute gradients gradient = model.gradient(X_test, variable='x1')
